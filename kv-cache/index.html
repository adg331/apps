NetApp AFX：让 KV Cache 成为可管理的存储资产

从"HBM 装不下就重算"到"分层驻留、按需回填、集群共享"。
⚡
TTFT 数量级下降
从"重算"变成"取数"：TTFT 从全量 prefill 的秒级，降到最佳层命中的毫秒级 —— 具体倍数随标定模型与命中层级变化，见第 3、4 幕实时数据。
📈
并发与吞吐提升
HBM 只留热块，同卡可承载更多活跃会话；prefill 算力被释放给 decode，GPU 有效利用率上升。
💰
单位成本下降
用 NVMe / 网络存储的 $/GB 承接 HBM 的容量压力，同等 SLA 下所需 GPU 数量减少。
🔗
集群级前缀共享
系统提示、知识库文档等公共前缀入 AFX 池共享，一处 prefill 全集群命中；GDS/RDMA 数据路径绕过 CPU，回填不抢算力。
