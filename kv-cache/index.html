用四个指标衡量共享 KV Cache 的收益

两项是收益：单卡吞吐和单卡并发会话。另两项是代价：带宽和容量的成本。评估方案时四项要一起看 —— 下一幕的 NetApp 实测，看的就是收益这一侧。
收益 · THROUGHPUT
TPS / GPU
每块 GPU 每秒生成的 token 数。省掉重复预填充后，算力用在生成上。
收益 · CONCURRENCY
会话数 / GPU
每块 GPU 能同时服务的会话数。上下文不必常驻显存，并发上限随之提高。
代价 · BANDWIDTH
$ / Gbps
读回 KV Cache 必须足够快，才能比重新计算更划算。带宽成本决定这笔账。
代价 · CAPACITY
TB / GPU
为更多会话保留 KV Cache 所需的容量。写入带宽还会影响闪存寿命，进而影响容量规划。
共享 KV Cache 带来的增益
提高吞吐：同样的 GPU 生成更多 token（TPS/GPU ↑）。
提高并发：同样的 GPU 承载更多会话（会话数/GPU ↑）。
降低首 token 时间：命中缓存的请求跳过大部分预填充，用户和智能体更快看到响应。
存储层需要满足的条件
读带宽：足够快地把 KV Cache 读回 GPU。
容量：能为更多会话长期保留 KV Cache。
写带宽与耐久：持续写入带来的闪存磨损，决定了需要多少容量来分摊寿命。
成本：以 $/Gbps 与 TB/GPU 衡量，控制带宽和容量的投入。
※ 指标定义依据 INSIGHT 2026 场次 BKO1025 讲者材料。

基础流程
Token
📖书里最小的"字/词"切分单位，AI 一次只能读写一个 token，不是一次读完一整句。
Attention注意力机制
📖读到当前这句话时，回头翻看前面哪几页跟它相关、该重点参考——"回头看"的动作本身。
KV CacheKey-Value Cache · 键值缓存
📖读书时随手记的"标签便签"：记下"这段讲的是什么、原文在哪"，下次不用重新翻整本书查。
Prefill预填充
📖拿到新书（新的问题/文档）后从头通读一遍、边读边做便签（生成 KV Cache）的过程——用户在这一步等待。
Decode解码 / 生成
📖笔记做完后，照着便签一字一句复述、组织答案的过程——对应逐 token 往外"吐字"。
自回归生成Autoregressive Generation
📖口述时必须先说完第 4 个字，才能决定第 5 个字说什么——不能跳着说，也不能想好整段再一次性倒出来。
TTFTTime To First Token · 首字延迟
📖从提出问题，到读完/记完笔记、说出第一个字之间的等待时间——用户感知到的"卡顿感"。
上下文长度Context Length
📖这本"书"（对话/文档）一共有多少字，决定了要记多少张便签、笔记本要多厚。
命中 / 未命中Cache Hit / Cache Miss
📖命中 = 便签还在手边，直接拿来用；未命中 = 便签丢了或没做过，得重新翻书通读一遍。
KV 体积怎么算（第 2 幕"每 token KV 大小"的四个参数）
层数Layers · 如 80 层
📖同一段内容反复读 80 遍、每遍都记一条笔记——不是重复抄同一件事，而是一层比一层读得更深（字面→逻辑→弦外之音）。层数越多，要记的笔记页数越多。
KV 头数KV Heads · 如 8 个（GQA）
📖同时开着几本不同角度的笔记本（时间线、人物关系、因果链……），每读一遍都从这几个角度分别记一条摘要。头数越多，同一处内容记的摘要份数越多。
head_dim每个头的维度大小 · 如 128
📖每条摘要用多少个数字来描述——数值越大，这条笔记能装下的细节越丰富，但笔记本身也越"厚"（占用空间越大）。
FP1616 位浮点精度
📖记笔记时"字迹的精细程度"：用多高精度记录每个数字。精度越高笔记越准，但每个字占的纸（存储空间）也越多——FP16 即每个数字用 2 字节记录。
模型架构优化（决定"笔记怎么记、记多快"）
GQAGrouped-Query Attention · 分组查询注意力
📖几个人共用同一份笔记本做参考，而不是每人各抄一份——省纸，对应省显存。
MLAMulti-head Latent Attention · 多头潜在注意力
📖不抄原文摘录，而是写一份高度浓缩的"精简笔记"，需要时再展开还原——笔记本身占地更小。
MoEMixture of Experts · 混合专家模型
📖书里遇到不同类型内容（法律条款/数学公式/日常对话），分别喊对应的"专家"来读、来记，而非每次全员出动。
DSADeepSeek Sparse Attention · 稀疏注意力
📖用书的"索引/目录"直接定位到相关的几页去参考，而不是每次都把全书翻一遍。
c4a / c128aDeepSeek/vLLM 内部代号，无官方全称
📖把连续 4 句/128 句话压缩成一张摘要卡片——比 MLA 更进一步的压缩粒度，笔记更薄。
